# Kabir Deewan

A mobile-first cricket prediction channel landing page using the supplied gold-and-dark design, royal SVG badge, statistics, Telegram join button, and ten-second automatic redirect.

The site uses plain HTML, CSS, and JavaScript with Google Fonts. No dependencies, database, or build step are required. Netlify publishes the project root.

To view locally, open `index.html` in a browser. The page automatically navigates to the supplied Telegram invite after ten seconds. Clicking the join button opens Telegram in a new tab and stops the automatic redirect in the original tab.

Edit `index.html` to change content or styling. Update both the button URL and `TELEGRAM_URL` when changing the invite. The displayed statistics and promotional claims are supplied page content, not live measurements.
